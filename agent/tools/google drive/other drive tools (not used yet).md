# other drive tools (not used yet)

Google Drive connector tools that haven't been tried. Descriptions come from the tool list, not from testing. When one is used, give it its own doc and remove it from here.

1. **copy\_file:** copies a file, with an optional new title and folder.  
2. **get\_file\_metadata:** details about one file (owner, dates, size, parent).  
3. **get\_file\_permissions:** who has access to a file.  
4. **share\_file:** shares a file with a person, group, Chat space or anyone with the link, as reader, commenter or writer. Ask Mark before using it.  
5. **list\_recent\_files:** recently used files.  
6. **list\_shared\_drives:** shared drives Mark can see.  
7. **get\_shared\_drive\_metadata:** details about one shared drive.
