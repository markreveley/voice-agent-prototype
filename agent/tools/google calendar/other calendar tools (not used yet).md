# other calendar tools (not used yet)

Google Calendar connector tools that haven't been tried. Descriptions come from the tool list, not from testing. When one is used, give it its own doc and remove it from here.

1. **search\_events:** finds events on the main calendar by meaning, not just exact words. Useful for checking today's events.  
2. **list\_events:** lists events in a time range.  
3. **get\_event:** full details of one event by ID.  
4. **list\_calendars:** the calendars Mark can see, with their IDs.  
5. **respond\_to\_event:** accept, decline or say maybe to an invitation.  
6. **suggest\_time:** suggests free time slots.

Note: the app also has device calendar tools (event\_create\_v1 and others) that write to the phone's Calendar app. They're separate from this connector.
