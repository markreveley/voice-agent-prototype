# evidence policy

*How claims about the system are backed by tests. Moved from agents.md (evidence protocol) in run 03 (2026-11-10). Each rule names the doctrine principle it serves (doctrine.md, root). IDs are fixed: never renumber or reuse one; retire an ID by marking it retired.*

## Rules

**evid-01 (serves doc-01) Cite or mark every claim.** New claims go in test findings.md only with a citation to a record in the tested folder, or marked "observed" or "not tested".

**evid-02 (serves doc-01) Fix contradicted claims.** If a test contradicts a claim, fix the claim and say so.

## Changing this policy

New rules go here with the next unused ID (evid-03, ...). Edit this file in Drive and commit; git keeps the old version.
